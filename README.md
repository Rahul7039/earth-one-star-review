# One Star, Five Stars for the Food

An alien tourist's one-star review of planet Earth — that still slips in a real compliment about the food. One sentence, 151 characters.

> "One star — I came to conquer, stayed because the dosa was glorious, and left because your species charges money for water that falls free from the sky."

## Run it

```bash
python3 main.py
```

This writes the review, byte-identical, to `/output/entry.txt`.

## About

A make.fun competition entry for [One Star, Five Stars for the Food](https://make.fun/competitions/u-po-pu-one-star-five-stars-for-the-food-f9166ee7). The entry program's only job is to write the chosen line to `/output/entry.txt`; the line is a fixed constant, never generated or paraphrased at runtime, and an assertion guards the 200-character limit and the single-sentence rule.
